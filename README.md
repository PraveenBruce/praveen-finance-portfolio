# Praveen S — Institutional Valuation & Quantitative Portfolio Architecture
A minimalist Starbase / architectural drafting portfolio showcasing institutional financial modeling, DCF valuation, LBO structuring, Bloomberg BMC analytics, and verified certifications.

## 🚀 Live Demo & Structure
- **`index.html`**: Main architectural portfolio interface featuring the 3D Finance Coin stage, Swiss Bento Executive Summary, 5-Card Interactive Credit Card Stack, and 6-Project Master File Folder Dossier.
- **`starbase_theme.css`**: Starbase minimalist design system with comprehensive responsive support across desktop, tablet, and mobile devices down to 320px.
- **`app.js`**: Interactive controller handling the canvas 3D coin, card cycling, master file tabs, and mobile navigation.
- **`assets/`**: High-resolution architectural portrait and verified SVG/PNG credentials.

## 💻 Local Development
Run the local server using PowerShell:
```powershell
powershell -ExecutionPolicy Bypass -File .\server.ps1
```
Then visit `http://localhost:8090` in your web browser.
